# MD Viewer — дизайн

**Дата:** 2026-08-04
**Статус:** утверждён пользователем

## Цель

Небольшое десктоп-приложение для красивого отображения Markdown-файлов в стиле GitHub:
рендер как на github.com, навигация по папке, поиск, оглавление, тёмная/светлая тема,
переключатель «рендер/исходник». Windows — основная платформа.

## Стек

- **Electron** (последний стабильный) — десктоп-оболочка
- **React 18 + Vite + TypeScript**, сборка через `electron-vite` (шаблон react-ts)
- **electron-builder** — сборка установщика (.exe, NSIS), включая регистрацию `.md` в Windows
- **Vitest** — юнит-тесты чистых функций

## Структура проекта

```
mdviewer/
├─ src/
│  ├─ main/        # Electron main-процесс (окна, IPC, файловая система)
│  ├─ preload/     # contextBridge-мост
│  └─ renderer/    # React-приложение
│     ├─ components/   # Toolbar, FileTree, TocSidebar, MarkdownView, SourceView, SearchBar, StatusBar
│     └─ lib/          # markdown-конвейер, toc, search, resolveImages (чистые функции)
├─ docs/superpowers/specs/
├─ demo.md              # образец со всеми фичами
└─ package.json
```

## Макет интерфейса

- **Верхняя панель (Toolbar):** «Открыть файл», «Открыть папку», путь к текущему файлу,
  строка поиска, переключатель темы 🌙/☀️, кнопки «Рендер/Исходник», «Оглавление» (вкл/выкл)
- **Левая панель (FileTree):** дерево папки; `.md`-файлы кликабельны, прочие файлы отображаются, но не открываются
- **Центр:** рендер документа в `.markdown-body` (оригинальные стили GitHub) либо исходник в `<pre>`
- **Правая панель (TocSidebar):** оглавление по заголовкам H1–H4, клик — плавный скролл к якорю
- **Статус-бар:** путь, кол-во найденных совпадений, сообщения об ошибках

## Конвейер рендеринга

1. `remark-parse` + `remark-gfm` — таблицы, task-листы, зачёркивание, автолинки
2. `remark-math` + `rehype-katex` — LaTeX-формулы (`$...$`, `$$...$$`), стили KaTeX
3. `rehype-highlight` (highlight.js) с темами `github` / `github-dark` — подсветка кода как на GitHub
4. `rehype-slug` + `rehype-autolink-headings` — id у заголовков и якорные ссылки 🔗
5. `rehype-raw` + `rehype-sanitize` — безопасный inline-HTML (без скриптов)
6. `github-markdown-css` — оригинальные стили GitHub; тёмная тема — `github-markdown-dark.css`
7. Mermaid: блоки ` ```mermaid ` рендерятся через `mermaid.render()` (async), при ошибке — сообщение вместо диаграммы
8. Относительные пути картинок (`![](img.png)`, HTML `<img src>`) резолвятся от папки md-файла в `file://` через main-процесс

Рендер в React через `dangerouslySetInnerHTML` с мемоизацией по содержимому.

## Открытие файлов

- Кнопки «Открыть файл» / «Открыть папку» — нативные диалоги через IPC
- **Drag&drop** `.md` или папки на окно
- **Ассоциация .md в Windows:** `electron-builder` → `fileAssociations` при установке;
  для dev-режима — npm-скрипт `register-assoc`, пишущий ключи HKCU в реестр
- Запуск с путём файла в argv (packaged) / событие `open-file` — открыть этот файл
- `requestSingleInstanceLock` + `second-instance`: повторный запуск фокусирует существующее окно и открывает файл

## Поиск

- Строка поиска в Toolbar; подсветка всех совпадений `<mark>`, счётчик «N из M»,
  кнопки «Следующее/Предыдущее» со скроллом к совпадению
- Поиск по рендеренному тексту (утилита-обёртка над text-нодами в `.markdown-body`)

## Тема

- Переключатель в Toolbar: светлая/тёмная (`github-markdown-light.css` / `github-markdown-dark.css`)
- Сохранение выбора в `localStorage`

## Безопасность

- `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`
- Доступ к ФС только через preload/IPC с явным белым списком операций:
  `readFile`, `readDir`, `pickFile`, `pickFolder`, `resolveImage`, `openPath`
- HTML-контент md проходит через `rehype-sanitize` (скрипты и опасные атрибуты удаляются)

## Обработка ошибок

- Ошибки чтения (нет доступа, битый файл) → сообщение в статус-баре, содержимое не меняется
- Ошибка Mermaid → placeholder с текстом ошибки
- Очень большие файлы → состояние загрузки, рендер асинхронно (без блокировки UI)
- Ошибка IPC → статус-бар, без краша окна

## Тестирование

- **Vitest**: юнит-тесты чистых функций — генерация TOC из HTML-заголовков,
  поиск/подсветка совпадений, резолв относительных путей изображений
- **Ручная проверка**: `demo.md` со всеми фичами (заголовки, таблицы, task-листы,
  код, формулы, Mermaid-диаграмма, картинки, HTML) — открыть в светлой и тёмной теме
