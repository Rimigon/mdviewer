# Копирование кода из блока в превью

Дата: 2026-08-09 · Статус: реализовано

## Задача

В превью у каждого блока кода появляется возможность быстро скопировать
весь его текст в буфер обмена.

## Решения

- **UI**: иконка копирования в правом верхнем углу блока, появляется при
  наведении (как на GitHub) и по фокусу с клавиатуры. Выбран вариант
  «кнопка при наведении»: двойной клик ломает выделение слова в коде,
  контекстное меню спрятано, постоянная кнопка шумит.
- **Механика**: кнопки вешаются на каждый `pre` в `MarkdownView.tsx` после
  рендера mermaid (диаграммы уже заменены на SVG — им кнопка не достаётся).
  Кнопка живёт только в DOM после вставки HTML, санитайзер не трогается.
- **Позиционирование**: каждый `pre` оборачивается в `.code-block-wrap`, кнопка
  — `position: absolute` в обёртке, а не внутри `pre`. Иначе флоат после inline-
  кода падал вниз блока, а скроллящийся pre увозил кнопку вместе с кодом.
  `data-src-line` переносится на обёртку для синхронного скролла.
- **Копирование**: `navigator.clipboard.writeText` с фолбэком на
  `execCommand` (lib/copyCode.ts). Текст — `code.textContent` с обрезанными
  концевыми переносами (`normalizeCodeText`).
- **Обратная связь**: тост «Скопировано» внизу по центру на ~1.5 сек,
  один элемент на превью, `role="status"`.
- **Безопасность**: SVG-иконка собирается через `createElementNS`, без
  `innerHTML`; пользовательский текст в DOM не попадает.
