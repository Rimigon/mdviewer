# Дизайн: настройка размера текста (просмотр + редактор)

Дата: 2026-08-06
Статус: одобрен пользователем

## Проблема

В mdviewer размер текста фиксирован: у превью/режима чтения базовый шрифт
16px (github-markdown-css, `.markdown-body`), у редактора CodeMirror — 13.5px.
Пользователю нужна возможность менять размер текста для просмотра и редактора
отдельно, с сохранением между запусками.

## Решение

Иконка «Aa» в тулбаре (рядом с переключателем темы) открывает поповер с двумя
слайдерами:

| Слайдер  | Что масштабирует                    | База   | Диапазон | Шаг |
|----------|-------------------------------------|--------|----------|-----|
| Просмотр | текст markdown-body (чтение/превью) | 16px   | 75–175%  | 5%  |
| Редактор | шрифт CodeMirror                    | 13.5px | 75–175%  | 5%  |

Значение показывается в процентах рядом со слайдером. По умолчанию — 100%.

## Архитектура

### Новый компонент `src/renderer/src/components/TextSizeControl.tsx`

Самодостаточный, состояние в App не поднимается:

- Хранит два значения (scale read / scale editor) в `localStorage`
  (ключи `fontScaleRead` / `fontScaleEditor`), применяет их как CSS-переменные
  на `document.documentElement`: `--font-scale-read`, `--font-scale-editor`.
- Читает сохранённые значения при монтировании; каждое значение валидируется
  (clamp в [0.75, 1.75]) — битые данные не ломают вёрстку.
- Поповер закрывается по клику мимо (прозрачный backdrop-перехватчик, не затемняет окно) и по Esc.
- Размещается в тулбаре рядом с кнопкой темы.

### Новая иконка

`TextSizeIcon` в `src/renderer/src/components/icons.tsx` — буквы «A» разного
размера (в стиле существующих inline SVG-иконок, stroke-based, 24×24).

### CSS (`src/renderer/src/styles/global.css`)

```css
:root { --font-scale-read: 1; --font-scale-editor: 1; }
.markdown-body { font-size: calc(16px * var(--font-scale-read)); }
.editor-pane .cm-editor { font-size: calc(13.5px * var(--font-scale-editor)); }
```

Плюс стили поповера и слайдера (нативный `<input type="range">` со
стилизацией под дизайн-систему: `--bg`, `--border`, `--accent`).

## Поведение

- Изменение размера просмотра пересчитывает высоты блоков; синхронный скролл
  не ломается, т.к. позиции блоков пересчитываются по текущей геометрии при
  скролле.
- Заголовки markdown (`h1`–`h6`) масштабируются пропорционально, т.к.
  используют `em` относительно базового размера.
- Смена темы не влияет на масштабы.

## Тестирование

Юнит-тест в `tests/` (по образцу существующих): логика чтения и валидации
значений из localStorage — корректное значение, отсутствующее значение,
битое значение (не число / вне диапазона).

## Сознательно опущено (YAGNI)

- Кнопка «Сброс» (слайдер легко вернуть в 100% вручную)
- Отдельные пресеты размеров
- Горячие клавиши для изменения размера
- Масштабирование дерева файлов / оглавления / тулбара
