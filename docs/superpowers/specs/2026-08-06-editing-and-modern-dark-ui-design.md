# Дизайн: редактирование markdown + современный тёмный UI

Дата: 2026-08-06
Статус: утверждён пользователем

## Контекст

**mdviewer** — просмотрщик Markdown на Electron + React. Сейчас приложение
только читает файлы: рендер в стиле GitHub, дерево папок, поиск, оглавление,
темы. Пользователь хочет:

1. Редактировать текст прямо в приложении (split-view редактор).
2. Более современный дизайн.
3. Без эмодзи (в UI сейчас есть ☀️/🌙, 📂/📁/📄 — все заменяются на SVG).

## Решения (согласованы с пользователем)

- Редактор: **split-view** (слева исходник, справа живое превью).
- Сохранение: **явное**, Ctrl+S + кнопка, индикатор dirty, диалог при закрытии.
- Дизайн: **тёмный по умолчанию** в стиле VS Code / Linear, светлая тема
  остаётся опцией.
- Движок редактора: **CodeMirror 6**.

## 1. Режимы просмотра

Вместо текущего переключателя «Рендер / Исходник» вводится переключатель
**«Правка» / «Просмотр»**:

| Режим | Состав |
| --- | --- |
| Правка | Слева CodeMirror-редактор, справа живое превью (рендер markdown), дерево файлов остаётся слева |
| Просмотр | Полный рендер как сейчас, с оглавлением справа |

- Превью обновляется с debounce ~300 мс после остановки ввода (рендер уже
  асинхронный: markdown pipeline + mermaid + изображения).
- Оглавление доступно только в режиме «Просмотр» (в split-режиме тесно,
  кнопка «Оглавление» скрыта/отключена).

## 2. Сохранение

### IPC

- Main-процесс: новый обработчик `fs:writeFile(path, content)` →
  `{ ok: true }` или бросает ошибку (renderer ловит и показывает в статус-баре).
- Preload: `window.api.saveFile(path, content): Promise<{ ok: boolean }>`.

### Состояние dirty

- `source` — актуальный текст редактора.
- `savedHash` (hash от последней сохранённой версии) — сравнение даёт dirty.
- Признаки dirty:
  - точка у имени файла в тулбаре;
  - надпись «Несохранённые изменения» в статус-баре.

### Ctrl+S

- В CodeMirror — через `keymap.of([{ key: "Mod-s", run: save }])`.
- В меню «Файл → Сохранить» (акселератор CmdOrCtrl+S) — событие
  `menu:save` → renderer сохраняет.

### Защита при закрытии окна

- Renderer зеркалит dirty-флаг в main через IPC `app:set-dirty`.
- Main перехватывает `close` окна: если dirty — `preventDefault` и нативный
  `dialog.showMessageBox` с кнопками:
  - «Сохранить и закрыть» → main шлёт renderer `app:save-before-close`,
    renderer сохраняет файл и отвечает `app:confirmed-close`, main закрывает;
  - «Не сохранять» → сброс флага, закрытие;
  - «Отмена» → ничего.
- Это надёжнее, чем `beforeunload` в renderer (главный процесс — источник
  решения о закрытии).

## 3. CodeMirror 6

Пакеты:
`codemirror`, `@codemirror/lang-markdown`, `@codemirror/language`,
`@codemirror/state`, `@codemirror/view`, `@codemirror/commands`,
`@codemirror/search`.

Новый компонент `EditorPane.tsx`:

- Обёртка над `EditorView` в React (useRef + useEffect).
- Внешние изменения `source` (загрузка файла) синхронизируются в редактор
  только если текст реально изменился (чтобы не ломать курсор/undo).
- `onChange` → наверх (App), оттуда debounce-рендер превью.
- Кастомная тёмная тема CodeMirror под палитру приложения (единый стиль с UI,
  не стандартная one-dark).
- Номера строк, подсветка markdown, поиск Ctrl+F.
- При переключении в «Просмотр» редактор размонтируется (превью строится из
  того же `source`).

## 4. Новый дизайн

### Токены

CSS-переменные `--color-*`, `--space-*`, `--radius-*` в `:root`; темы — через
`html[data-theme="dark"]` / `"light"`. Тёмная — по умолчанию.

Палитра (тёмная): фон приложения `#16181d`, панели `#1d2027`, рамки `#2a2f3a`,
текст `#e8eaed`, приглушённый текст `#9aa4b2`, акцент — спокойный синий
`#4c8bf5`, hover-фон `rgba(255,255,255,0.06)`.

Светлая тема — отполированная версия текущей GitHub-палитры.

### Иконки (SVG, без эмодзи)

Все inline-SVG-иконки заменяют эмодзи и текстовые кнопки:

- Открыть файл, Открыть папку, Сохранить, Переключить режим (карандаш/глаз),
  Оглавление, Тема (луна/солнце), Поиск (лупа), дерево: шеврон, папка, файл.

### Компоненты

- Тулбар: компактный, тонкая нижняя рамка, иконки с `title`-tooltip'ами,
  путь файла по центру/слева, dirty-точка у имени.
- Кнопки: аккуратные, скруглённые, hover-состояние, active-состояние.
- Дерево файлов: иконки-шевроны + папка/файл, индентация, подсветка
  активного файла.
- Статус-бар: путь, строка/колонка из CodeMirror, dirty-статус.
- Типографика: системный стек, компактные размеры, tabular-numbers где нужно.

### Стиль

Без AI-клише: без фиолетовых градиентов, glassmorphism, glow-орбов и
sparkles-иконок. Тонкие рамки, умеренные тени, спокойный акцент.

## 5. Обработка ошибок

- Ошибка чтения/записи → статус-бар (текст ошибки).
- Ошибка сохранения → статус-бар + dirty остаётся, файл не «теряется».
- Нет открытого файла → пустое состояние (редактор недоступен).

## 6. Тесты и проверка

- Существующие vitest-тесты (markdown-конвейер, TOC, поиск) остаются зелёными.
- `npm run typecheck` и `npm run build` — чистые.
- Проверка вручную через `npm run dev`: загрузка demo.md, правка, Ctrl+S,
  dirty-индикатор, диалог закрытия, переключение режимов, темы.

- `src/shared/types.ts` — результат записи, типы IPC.
- `src/main/index.ts` — `fs:writeFile`, `app:set-dirty`, close-диалог,
  пункт меню «Сохранить».
- `src/preload/index.ts` — `saveFile`, `setDirty`, `onSaveAction`,
  `onSaveBeforeClose`, `confirmClose`.
- `src/renderer/src/components/EditorPane.tsx` — новый, CodeMirror-обёртка.
- `src/renderer/src/components/icons.tsx` — новый, набор SVG-иконок.
- `src/renderer/src/App.tsx` — режимы, dirty, debounce, сохранение.
- `src/renderer/src/components/FileTree.tsx`, `SearchBar.tsx`,

- `src/renderer/src/styles/global.css` — дизайн-система (токены + компоненты).

## Не входит в объём

- Кастомный frameless-тайтлбар окна.
- Автосохранение.
- WYSIWYG-редактирование (contenteditable).
- Автодополнение/рефакторинг IDE-уровня.
